# Brainstorming CollabWave

Antes de criar funcionalidades ou alterar comportamento, confirmar objetivo, fluxo do utilizador, contrato REST ou Socket.IO, persistência PostgreSQL, uso de Redis e critérios de aceitação.

Inspecionar primeiro o código relevante. Apresentar uma proposta simples, riscos, alternativas e testes. Não implementar até a direção estar definida quando a decisão alterar produto, dados ou contrato público.
